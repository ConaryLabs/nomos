# signed-world (working name)

An exploratory design thesis for a game engine whose primary author is a large
language model — and, eventually, the executable kernel that tests it.

- [THESIS.md](THESIS.md) — the design, the reasoning, the resolved
  disagreements, the proof gates, and the adoption criteria.
- [KERNEL.md](KERNEL.md) — acceptance criteria for the first artifact, written
  before any code.

**License:** MIT.

**Status:** exploratory, non-authoritative, no implementation commitment. This
is a clean-room exercise: it takes no project's history as given and binds no
project until that project records an explicit adoption decision.

Authored 2026-08-21 by two model families in adversarial review (Claude Fable 5
and GPT Pro), with Peter Permenter as owner and referee.

> The agent names the thing. Namespaces own state. Capabilities define
> obligations. The resolver composes effective facts. Projection compilers own
> the consequences. The runtime executes a sealed world. The renderer owns every
> pixel. A cold stranger can rebuild and explain all of it.
