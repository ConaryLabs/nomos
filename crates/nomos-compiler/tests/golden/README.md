# Construction golden epochs

`gaol-world-ir-nomos-construction-v3.sha256` is the active Nomos construction
golden. Version 3 adds the closed light-union resolver plan. Version 2, which
replaced string provenance fields with typed semantic identities and edges, and
version 1, the first Nomos construction shape, remain immutable historical
evidence.

The three `gaol-world-ir-construction-v*.sha256` files are immutable hashes from
the closed `estate.world_ir.construction@1..3` prototype epoch. They remain here
as provenance; no active test or schema consumes them.

`gaol-world-ir-nomos-v1.sha256` begins the stable World IR migration lineage;
it is not derived by renaming a construction golden. `gaol-package-nomos-v1.sha256`
pins the complete package manifest body produced from that stable artifact and
all four independently versioned projections.
