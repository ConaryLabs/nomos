# Construction golden epochs

`gaol-world-ir-nomos-construction-v2.sha256` is the active Nomos construction
golden. Version 2 replaces string provenance fields with typed semantic
identities and edges. `gaol-world-ir-nomos-construction-v1.sha256` preserves the
first Nomos construction shape introduced by contract revision 6.

The three `gaol-world-ir-construction-v*.sha256` files are immutable hashes from
the closed `estate.world_ir.construction@1..3` prototype epoch. They remain here
as provenance; no active test or schema consumes them.
